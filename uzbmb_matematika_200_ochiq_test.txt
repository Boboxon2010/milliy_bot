--- [OSON DARAJA (1 - 30)] ---

1. 25 ning 20% ini toping.
Javob: 5
Tushuntirish: 25 * 0.20 = 5.

2. 3x - 7 = 11 tenglamani yeching.
Javob: 6
Tushuntirish: 3x = 18 => x = 6.

3. Kvadratning perimetri 36 cm ga teng. Unining yuzini (cm²) toping.
Javob: 81
Tushuntirish: Tomoni a = 36 / 4 = 9 cm. Yuzi S = a² = 9² = 81 cm².

4. EKUB(36, 48) ni hisoblang.
Javob: 12
Tushuntirish: 36 va 48 ning eng katta umumiy bo'luvchisi 12 ga teng.

5. EKUK(12, 18) ni hisoblang.
Javob: 36
Tushuntirish: 12 va 18 ning eng kichik umumiy karralisi 36 ga teng.

6. Expression qiymatini toping: 2³ + 3² * 4.
Javob: 44
Tushuntirish: 8 + 9 * 4 = 8 + 36 = 44.

7. Tenglamani yeching: |x - 4| = 7 (musbat ildizini toping).
Javob: 11
Tushuntirish: x - 4 = 7 => x = 11; x - 4 = -7 => x = -3. Musbat ildiz 11.

8. Teng yonli uchburchakning asosidagi burchagi 50° bo'lsa, uning uchidagi burchagini toping.
Javob: 80
Tushuntirish: 180° - 2 * 50° = 80°.

9. log₂ (32) qiymatini toping.
Javob: 5
Tushuntirish: 2⁵ = 32 bo'lgani uchun log₂ (32) = 5.

10. sin(30°) + cos(60°) yig'indisini hisoblang.
Javob: 1
Tushuntirish: 1/2 + 1/2 = 1.

11. Arifmetik progressiyada a₁ = 3 va d = 4 bo'lsa, a₅ ni toping.
Javob: 19
Tushuntirish: a₅ = a₁ + 4d = 3 + 4 * 4 = 19.

12. Geometrik progressiyada b₁ = 2 va q = 3 bo'lsa, b₄ ni toping.
Javob: 54
Tushuntirish: b₄ = b₁ * q³ = 2 * 3³ = 2 * 27 = 54.

13. x² - 9 = 0 tenglamaning eng katta ildizini toping.
Javob: 3
Tushuntirish: x = ±3. Eng katta ildizi 3.

14. Radiusi 5 cm bo'lgan doiraning yuzini toping (π o'rniga 3 deb oling).
Javob: 75
Tushuntirish: S = π * r² = 3 * 5² = 75 cm².

15. Amamalni bajaring: (2/3) + (1/6). (Oddiy kasr javobini o'nli kasrda yozing: masalan 0.5)
Javob: 0.833 (yoki 5/6)
Tushuntirish: 4/6 + 1/6 = 5/6.

16. To'g'ri burchakli uchburchakning gipotenuzasi 10 cm, bir kateti 6 cm. Ikkinchi katetni toping.
Javob: 8
Tushuntirish: Pifagor teoremasiga ko'ra: b = √(10² - 6²) = √(100 - 36) = √64 = 8.

17. y = 2x + 5 funksiyaning x = 3 bo'lgandagi qiymatini toping.
Javob: 11
Tushuntirish: y = 2(3) + 5 = 11.

18. 0.25 sonini foizda ifodalang.
Javob: 25
Tushuntirish: 0.25 * 100 = 25%.

19. kubning qirrasi 4 cm. Uning hajmini (cm³) toping.
Javob: 64
Tushuntirish: V = a³ = 4³ = 64 cm³.

20. 5! (5 faktorial) nechaga teng?
Javob: 120
Tushuntirish: 1 * 2 * 3 * 4 * 5 = 120.

21. Tengsizlikni yeching: 2x - 6 > 4. x ning eng kichik butun qiymatini toping.
Javob: 6
Tushuntirish: 2x > 10 => x > 5. Eng kichik butun qiymat 6.

22. A(2, 3) va B(5, 7) nuqtalar orasidagi masofani toping.
Javob: 5
Tushuntirish: d = √((5-2)² + (7-3)²) = √(3² + 4²) = √25 = 5.

23. y = x² - 4x + 3 parabolaning uchining x-koordinatasini (x₀) toping.
Javob: 2
Tushuntirish: x₀ = -b / (2a) = -(-4) / (2 * 1) = 2.

24. Kasrni qisqartiring: (x² - 4) / (x - 2). Natijada hosil bo'lgan ifodaga x = 5 qo'ygandagi qiymatni toping.
Javob: 7
Tushuntirish: (x - 2)(x + 2) / (x - 2) = x + 2. x = 5 da: 5 + 2 = 7.

25. Proporsiyadan x ni toping: 3 / 4 = x / 12.
Javob: 9
Tushuntirish: 4x = 36 => x = 9.

26. Rombning diagonallari 6 cm va 8 cm. Uning yuzini toping.
Javob: 24
Tushuntirish: S = (d₁ * d₂) / 2 = (6 * 8) / 2 = 24 cm².

27. 3ⁿ = 81 bo'lsa, n ning qiymatini toping.
Javob: 4
Tushuntirish: 3⁴ = 81 bo'lgani uchun n = 4.

28. Muntazam oltiburchakning ichki burchaklari yig'indisini (darajada) toping.
Javob: 720
Tushuntirish: S = (n - 2) * 180° = (6 - 2) * 180° = 720°.

29. f(x) = x³ - 2x funksiyaning hosilasini x = 2 nuqtada hisoblang.
Javob: 10
Tushuntirish: f'(x) = 3x² - 2. f'(2) = 3(2²) - 2 = 12 - 2 = 10.

30. Vektor a = (3, 4) ning uzunligini (modulini) toping.
Javob: 5
Tushuntirish: |a| = √(3² + 4²) = √25 = 5.

--- [O'RTACHA DARAJA (31 - 150)] ---

31. Tenglamalar sistemasini yeching va x + y ni toping:
{ 2x + y = 10
{ x - y = 2
Javob: 6
Tushuntirish: Qo'shib yuborsak: 3x = 12 => x = 4. y = 2. x + y = 6.

32. Viyet teoremasidan foydalanib, x² - 7x + 12 = 0 tenglamaning ildizlari kvadratlari yig'indisini (x₁² + x₂²) toping.
Javob: 25
Tushuntirish: x₁ + x₂ = 7, x₁*x₂ = 12. x₁² + x₂² = (x₁ + x₂)² - 2x₁x₂ = 49 - 24 = 25.

33. Tengsizlikni yeching: (x - 1)(x - 3) ≤ 0. Yechimlar oralig'idagi butun sonlar yig'indisini toping.
Javob: 6
Tushuntirish: x ∈ [1, 3]. Butun yechimlar: 1, 2, 3. Yig'indi: 1 + 2 + 3 = 6.

34. Arifmetik progressiyada S₁₀ = 150 va a₁ = 3 bo'lsa, ayirma d ni toping.
Javob: 2.67 (yoki 8/3)
Tushuntirish: S₁₀ = (2a₁ + 9d)/2 * 10 = (6 + 9d) * 5 = 150 => 6 + 9d = 30 => 9d = 24 => d = 8/3.

35. Korsatgichli tenglamani yeching: 4ˣ⁺¹ - 2ˣ⁺² = 32.
Javob: 2
Tushuntirish: 4 * 2²ˣ - 4 * 2ˣ = 32 => 2²ˣ - 2ˣ - 8 = 0. t = 2ˣ => t² - t - 8 = 0... t = 4 => 2ˣ = 4 => x = 2.

36. Logarifmik tenglamani yeching: log₃(x - 2) + log₃(x + 4) = 3.
Javob: 5
Tushuntirish: log₃((x-2)(x+4)) = 3 => x² + 2x - 8 = 27 => x² + 2x - 35 = 0. (x+7)(x-5)=0. x > 2 bo'lishi kerak => x = 5.

37. Trigonomerik tenglama: 2sin²x + sinx - 1 = 0 tenglamaning [0; π] oralig'idagi ildizlari sonini toping.
Javob: 2
Tushuntirish: t = sinx => 2t² + t - 1 = 0 => t = 1/2 yoki t = -1. sinx = 1/2 ning [0, π] da 2 ta ildizi bor (π/6 va 5π/6).

38. Trapetsiyaning asoslari 8 cm va 14 cm, balandligi 6 cm. Trapetsiya yuzini toping.
Javob: 66
Tushuntirish: S = ((a + b) / 2) * h = ((8 + 14) / 2) * 6 = 11 * 6 = 66 cm².

39. To'g'ri to'rtburchakning perimetri 28 cm, yuzi 48 cm². Uning diogonalini toping.
Javob: 10
Tushuntirish: a + b = 14, a * b = 48 => a = 6, b = 8. Dioganal d = √(6² + 8²) = 10.

40. Integralni hisoblang: ∫₀² (3x² - 2x + 1) dx.
Javob: 6
Tushuntirish: [x³ - x² + x]₀² = (8 - 4 + 2) - 0 = 6.

41. Teng yonli trapetsiyaning kichik asosi 6 cm, yon tomoni 5 cm, balandligi 4 cm. Katta asosini toping.
Javob: 12
Tushuntirish: Yon tomondan pastga proektsiya x = √(5² - 4²) = 3 cm. Katta asos a = 6 + 2*3 = 12 cm.

42. Slindrning balandligi 8 cm, asosining radiusi 3 cm. Slindrning yon sirtining yuzini toping (π = 3 deb oling).
Javob: 144
Tushuntirish: S_yon = 2πRh = 2 * 3 * 3 * 8 = 144 cm².

43. Konusning yasovchisi 10 cm, balandligi 8 cm. Konusning hajmini toping (π = 3 deb oling).
Javob: 288
Tushuntirish: R = √(10² - 8²) = 6. V = (1/3) * π * R² * h = (1/3) * 3 * 36 * 8 = 288 cm³.

44. Sferaning yuzi 144π cm². Sferaning radiusini toping.
Javob: 6
Tushuntirish: S = 4πR² = 144π => R² = 36 => R = 6 cm.

45. Chiziqli funksiya y = kx + b (1, 5) va (3, 11) nuqtalardan o'tsa, k + b yig'indisini toping.
Javob: 5
Tushuntirish: 5 = k + b va 11 = 3k + b. Ayirsak: 2k = 6 => k = 3, b = 2. k + b = 5.

46. x³ - 3x² - 4x + 12 = 0 tenglamaning eng katta va eng kichik ildizlari ko'paytmasini toping.
Javob: -6
Tushuntirish: x²(x - 3) - 4(x - 3) = 0 => (x² - 4)(x - 3) = 0 => Ildizlar: -2, 2, 3. Eng kichik (-2) * eng katta (3) = -6.

47. Birlashmalari (kombinatorika): C(8, 3) ni hisoblang.
Javob: 56
Tushuntirish: 8! / (3! * 5!) = (8 * 7 * 6) / (3 * 2 * 1) = 56.

48. O'rinlashtirishlar (kombinatorika): A(6, 2) ni hisoblang.
Javob: 30
Tushuntirish: 6! / (6 - 2)! = 6 * 5 = 30.

49. Ikki kubik bir vaqtda tashlanganda tushgan ochkolar yig'indisi 8 bo'lish ehtimolini toping (javobni kasr yoki o'nli ko'rinishda: 5/36).
Javob: 0.139 (yoki 5/36)
Tushuntirish: Mos keluvchi juftliklar: (2,6), (3,5), (4,4), (5,3), (6,2) - jami 5 ta. Jami holatlar 36 ta. P = 5/36.

50. f(x) = e²ˣ * sin(x) funksiyaning hosilasini f'(0) hisoblang.
Javob: 1
Tushuntirish: f'(x) = 2e²ˣ*sinx + e²ˣ*cosx. f'(0) = 2(1)(0) + (1)(1) = 1.

51. Geometrik progressiyaning cheksiz kamayuvchi yig'indisi S = 12 va b₁ = 4 bo'lsa, mahraj q ni toping.
Javob: 0.667 (yoki 2/3)
Tushuntirish: S = b₁ / (1 - q) => 12 = 4 / (1 - q) => 1 - q = 1/3 => q = 2/3.

52. Tenglamani yeching: √(2x + 5) = x - 1.
Javob: 4
Tushuntirish: Kvadratga ko'tarsak: 2x + 5 = x² - 2x + 1 => x² - 4x - 4 = 0... Chet ildizlarni chiqarsak, x = 4.

53. Barcha ikki xonali musbat sonlar yig'indisini toping.
Javob: 4905
Tushuntirish: a₁ = 10, aₙ = 99, n = 90. S = (10 + 99)/2 * 90 = 109 * 45 = 4905.

54. y = |x - 3| + |x + 2| funksiyaning eng kichik qiymatini toping.
Javob: 5
Tushuntirish: Uchburchak tengsizligiga ko'ra: |x - 3| + |x + 2| ≥ |(3 - x) + (x + 2)| = 5.

55. cos(2x) = 0 tenglamaning [0; π] kesmadagi ildizlari yig'indisini toping (π o'rniga 3.14 deb oling yoki radian ko'rinishida π).
Javob: 3.14 (yoki π)
Tushuntirish: 2x = π/2 + πk => x = π/4 va x = 3π/4. Yig'indi: π/4 + 3π/4 = π ≈ 3.14.

56. Parallelogrammning tomonlari 5 cm va 8 cm, ular orasidagi burchak 30°. Parallelogramm yuzini toping.
Javob: 20
Tushuntirish: S = a * b * sin(α) = 5 * 8 * sin(30°) = 40 * 0.5 = 20 cm².

57. Limitni hisoblang: lim (x -> 2) (x² - 4) / (x - 2).
Javob: 4
Tushuntirish: lim (x -> 2) (x + 2) = 2 + 2 = 4.

58. Uchburchakning tomonlari 5, 7 va 8 cm. Eng katta burchak kosinusini (cos α) toping.
Javob: 0.143 (yoki 1/7)
Tushuntirish: Kosinuslar teoremasi: 8² = 5² + 7² - 2*5*7*cos α => 64 = 25 + 49 - 70 cos α => 70 cos α = 10 => cos α = 1/7.

59. 2ˡᵒᵍ²⁽⁵⁾ + log₃(81) / 2 iboraning qiymatini toping.
Javob: 7
Tushuntirish: 2ˡᵒᵍ²⁽⁵⁾ = 5. log₃(81) = 4, 4/2 = 2. Natija: 5 + 2 = 7.

60. Piramidaning asosi yuzi 36 cm², balandligi 9 cm. Piramida hajmini toping.
Javob: 108
Tushuntirish: V = (1/3) * S_asosi * h = (1/3) * 36 * 9 = 108 cm³.

--- [QIYIN DARAJA (151 - 200)] ---

151. Aniq integralni hisoblang: ∫₀^(π/2) x * cos(x) dx.
Javob: 0.571 (yoki π/2 - 1)
Tushuntirish: Bo'laklab integrallash: u = x, dv = cos(x)dx => [x*sin(x)]₀^(π/2) - ∫₀^(π/2) sin(x)dx = (π/2 - 0) + [cos(x)]₀^(π/2) = π/2 - 1 ≈ 1.571 - 1 = 0.571.

152. Tengsizliklar sistemasini yeching va butun yechimlar sonini toping:
{ log₀.₅(x² - 5x + 6) ≥ -1
{ |x - 2| < 3
Javob: 2
Tushuntirish: Birinchi tengsizlik: x² - 5x + 6 ≤ 2 va x² - 5x + 6 > 0 => x ∈ [1, 2) U (3, 4]. Ikkinchi: -1 < x < 5. Umumiy yechim: [1, 2) U (3, 4]. Butun yechimlar: 1 va 4 (2 ta).

153. Uchburchakning ikki tomoni 4 cm va 6 cm, ularga o'tkazilgan medianalar o'zaro perpendikulyar. Uchburchakning uchinchi tomonini toping.
Javob: 4.47 (yoki 2√5)
Tushuntirish: Medianalar xossalari va Pifagor teoremasidan: c = √((a² + b²)/5) = √((16 + 36)/5) = √(52/5) = 2√5.

154. f(x) = x³ - 3x + 2 funksiyaning [-2; 2] kesmadagi eng katta va eng kichik qiymatlari yig'indisini toping.
Javob: 4
Tushuntirish: f'(x) = 3x² - 3 = 0 => x = ±1. f(-2) = 0, f(-1) = 4, f(1) = 0, f(2) = 4. max = 4, min = 0. Yig'indi = 4.

155. Parametr a ning qanday eng kichik butun qiymatida x² - 2(a - 1)x + (a + 5) = 0 tenglama ikkita har xil haqiqiy musbat ildizga ega bo'ladi?
Javob: 5
Tushuntirish: D > 0, x₁ + x₂ > 0, x₁*x₂ > 0 shartlaridan: (a-1)² - (a+5) > 0 => a² - 3a - 4 > 0 => a > 4 yoki a < -1. x₁+x₂ = 2(a-1) > 0 => a > 1. x₁*x₂ = a+5 > 0 => a > -5. Umumiy: a > 4. Eng kichik butun qiymat: 5.
